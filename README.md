git status# 📱 Ciputra Network Manager

**Ciputra Network Manager** is a Flutter-based application designed to help manage member networks and organizational relationships efficiently.

The application provides a modern and user-friendly interface for managing member information, network structures, and related activities.

## ✨ Features

- 👥 Member Management
- 🌐 Network Management
- 🔐 User Authentication
- 📊 Dashboard Overview
- 🔎 Search and Filter Members
- 📱 Responsive User Interface
- ⚡ Built with Flutter

## 🛠️ Tech Stack

This project is built using:

- **Flutter**
- **Dart**
- **Material Design**

lib/

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your machine.

```bash
flutter --version
```

For Flutter installation instructions, visit the official Flutter documentation.

### Installation

Clone this repository:

```bash
git clone https://github.com/chsryn/ciputra-network-manager.git
```

Navigate to the project directory:

```bash
cd ciputra-network-manager
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
